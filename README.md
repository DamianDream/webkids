# 🕵️‍♂️ WebKids — Кибер-Академия Спецагентов

Интерактивная образовательная веб-платформа для обучения детей основам веб-разработки (HTML и CSS) в формате шпионского квеста. Построена на [Astro](https://astro.build/).

---

## 🌟 Возможности и особенности

- 🎮 **Игровой формат спецагента**: Ребёнок раскрывает «секретные дела», набирает опыт (XP), повышает звание от «Стажёра» до «Главы Академии» и получает именной Золотой Диплом.
- 📱 **Векторный интерактивный iPad Pro**: Реалистичный симулятор планшета с браузером Safari, адаптирующийся под любые экраны без потери качества.
- ⌨️ **Практика с чистого листа**: Редактор кода пустой — ребёнок пишет теги самостоятельно своими руками (без автоподстановок), вырабатывая навык вёрстки.
- 🧩 **Шпаргалка тегов**: Быстрые кнопки-стикеры для вставки шаблонов тегов (`<h1>`, `<p>`, `<b>`, `<i>`, `<ul>`, `<img>`, `<a>`, `<button>`, `<style>`).
- 🏛️ **«Анатомия сайта» (Дело №0)**: Наглядный серый каркас `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`. Первые системные теги даются для ознакомления с автоматической подсветкой и не требуют ручного ввода.
- ⚡ **Две кнопки действия**:
  - `▶ Запустить` — отображает текущую вёрстку на iPad с анимацией обновления.
  - `✓ Проверить` — валидирует выполнение секретного задания, начисляет XP и выводит конфетти.
- 📖 **Книга Тегов**: Встроенный интерактивный справочник со шпионскими метафорами, аналогиями и готовыми сниппетами для копирования.
- 💾 **Автосохранение 100%**: Весь прогресс (код по каждому шагу, выполненные задачи, XP, позывной и аватар) надёжно сохраняется в браузере (`localStorage`).
- 🔊 **Звуковые эффекты**: Встроенный синтезатор на Web Audio API (звуки кликов, побед, начисления XP) и переключатель звука.

---

## 📂 Структура уроков

- **Дело №0**: Чертёж сайта (Анатомия HTML: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- **Дело №1**: Первые слова шпиона (`<h1>` и `<p>`)
- **Дело №2**: Маскировка текста (Жирный `<b>` и курсив `<i>`)
- **Дело №3**: Секретный инвентарь (Списки `<ul>` и `<li>`)
- **Дело №4**: Фотодосье и секретные порталы (Картинки `<img>` и ссылки `<a>`)
- **Дело №5**: Цвета штаба и лазерная кнопка (CSS `<style>`, стили и интерактивная `<button>`)
- **Дело №6**: Финальная спецоперация (Сборка полноценного досье героя и печать Диплома)

## 🚀 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/DamianDream/webkids.git
cd webkids

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка статического сайта
npm run build

# Предпросмотр собранного проекта
npm run preview
```
